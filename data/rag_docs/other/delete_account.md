# Удаление аккаунта

Чтобы удалить аккаунт и персональные данные:

1. Настройки → Аккаунт → «Удалить аккаунт».
2. Подтвердите паролем и кодом из email.
3. Данные удаляются в течение **30 дней** (период восстановления).
4. Активная подписка отменяется; возврат — по правилам биллинга.

После удаления войти будет нельзя. Экспортируйте нужные данные заранее.
