# Язык интерфейса

Доступные языки: русский и английский.

Смена языка: Настройки → Язык → выбрать RU или EN. Изменение применяется сразу; часть системных писем может приходить на языке, выбранном при регистрации, до обновления профиля.

Другие языки пока не поддерживаются — можно оставить запрос через «Обратная связь».
