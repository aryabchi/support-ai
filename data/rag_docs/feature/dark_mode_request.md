# Тёмная тема интерфейса

Многие пользователи просят системную тёмную тему.

Текущий статус: в бэклоге на ближайший квартал. Временный обходной путь — системный «ночной режим» ОС и уменьшение яркости.

Чтобы проголосовать за приоритет: Настройки → Обратная связь → «Тёмная тема». Чем больше голосов, тем выше приоритет в роадмапе.
