# Экспорт данных в CSV

Запрос на выгрузку проектов и отчётов в CSV.

Сейчас доступен экспорт в PDF из раздела «Отчёты». CSV-экспорт планируется:

1. Список задач проекта.
2. История платежей (для админов workspace).

Пока можно скопировать таблицу вручную или запросить выгрузку у поддержки для аккаунтов Про.
