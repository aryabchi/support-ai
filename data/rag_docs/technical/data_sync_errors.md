# Ошибки синхронизации данных

Если данные не синхронизируются между устройствами:

1. Проверьте стабильное интернет-соединение (Wi‑Fi предпочтительнее).
2. Выйдите из аккаунта и войдите снова.
3. В настройках приложения включите «Синхронизация в фоне».
4. Дождитесь окончания синхронизации (индикатор в шапке приложения).

Конфликты версий: сохраняется последняя успешная запись на сервере. Локальные черновики можно восстановить из «Недавние изменения».
