# Приложение не запускается

Если приложение не открывается или сразу закрывается:

1. Обновите приложение до последней версии из магазина.
2. Перезапустите устройство.
3. Освободите место на диске (нужно минимум 200 МБ свободно).
4. Переустановите приложение (данные аккаунта сохранятся на сервере).
5. На Android: очистите кэш приложения в настройках системы.

Пришлите версию ОС и номер сборки приложения, если проблема останется.
